Arcmira brand assets exported from the existing vector mark at https://arcmira.com/icon.svg. The path geometry is unchanged. These monochrome exports omit the square favicon background and retain transparent padding.

- `square.png`: 256 × 256 pixels.
- `rectangle.png`: 512 × 190 pixels.

The matching SVG sources are included. Export with `rsvg-convert square.svg -o square.png` and `rsvg-convert rectangle.svg -o rectangle.png`.
